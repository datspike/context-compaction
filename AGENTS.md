# AGENTS.md — context-compaction

Публичное Pi-расширение. Исходник истины — этот репозиторий; в Pi устанавливается из unpinned Git-источника через `pi install git:github.com/datspike/context-compaction`, а локально проверяется через `pi install -l`.

## Проверки и публикация

Перед завершением изменений запускай `npm run verify`, `npm pack --dry-run` и `git diff --check`. Пакет и Git не должны содержать `.task_files/`, `.runtime/`, `.pi/`, `AGENTS.local.md`, сырые сессии, конфиги провайдера и секреты.
Сообщения новых коммитов: `type(scope): краткое описание`; один коммит — одно связное изменение. Подготовка плана сама по себе не разрешает commit, push или PR.

## Контекст и процесс

Поведение и контракты описаны в README.md; меняй его вместе с кодом. Переносимый процесс — в `docs/workflows.md`.
Если есть `AGENTS.local.md`, прочитай его перед выбором задачи, после compact/resume и смены worktree. Он указывает канонический приватный индекс; отсутствие локальных планов не мешает обычному публичному вкладу.
Для изменений публичного контракта, зависимостей или границ сессии сначала зафиксируй согласованное решение в ADR. Незакрытые варианты оставляй в приватном плане; ADR не нужен для обычной локальной правки.
При сравнении способов compact проверяй сохранение пользовательского результата, ограничений и причин решений, а не только длину summary. Исходные сессии не переписывай; модельные прогоны требуют отдельного согласованного бюджета.
