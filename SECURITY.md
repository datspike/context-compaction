# Безопасность

Не публикуйте в issue, pull request и логах ключи, токены, пароли, содержимое `.env` и другие закрытые данные.

Если вы обнаружили уязвимость, используйте private security advisory GitHub. Не создавайте публичный issue с подробностями до согласования исправления.

При проверке изменений убедитесь, что секрет отсутствует не только в рабочем дереве, но и во всех коммитах и refs, которые могут попасть в публичный remote.
