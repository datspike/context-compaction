# Идентификатор ответа для связи телеметрии

В существующее поле `responses.flags_json` добавляется необязательный `providerResponseId` из итогового `AssistantMessage.responseId`. Значение сохраняется только для строкового идентификатора; отсутствие не заменяется синтетическим значением.

Это связывает измерение с меткой режима другого расширения по точному ответу, сессии и модели. Схема SQLite, временные границы и расчёт скорости не меняются. Старые строки не переписываются. Текст модели, запрос, ключи и HTTP-заголовки не сохраняются.

Альтернатива — сопоставлять по времени или порядку. Она отвергнута: повторы, переключения Fast и незавершённые ответы делают связь неоднозначной. Импортировать Fast-расширение или создавать отдельный канал событий в сборщике не требуется.
